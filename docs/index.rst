BhashaBridge Documentation
==========================

**Don't just translate words. Understand the vibe.**

BhashaBridge is a context-aware Telegram bot that explains Indian code-mixed language
(Hinglish, Kanglish, etc.) to English speakers using Gemini AI. It features smart
auto-reply generation, tone detection, and multi-language translation—all operating
invisibly in inline mode.

Features
--------

* **Invisible Inline Mode** - All interactions via inline queries, invisible to other group members
* **Silent Learning** - Listens to group conversations without interrupting
* **Context-Aware Explanations** - Understands slang and cultural context
* **Multi-Language Support** - English, Hindi, and Kannada
* **Smart Auto-Reply** - Generates contextual replies with tone detection
* **Dual Memory System** - Short-term sliding window + long-term persistent storage
* **Intelligent Retrieval** - Only relevant memories are injected into prompts
